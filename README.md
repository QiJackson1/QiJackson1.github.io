# Jason Qi · Personal Homepage

Jason Qi's personal website, featuring robotics, embodied intelligence, motor control, publications, patents, and engineering projects.

## Local Development

Requires Node.js 22 or later.

```bash
npm install
npm run dev
```

## Deployment

The repository includes a GitHub Pages workflow. Pushing to the `main` branch of `QiJackson1/QiJackson1.github.io` automatically builds and deploys the site to `https://qijackson1.github.io/`.
